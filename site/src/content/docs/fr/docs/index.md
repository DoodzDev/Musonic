Cette documentation s'adresse à ceux qui font tourner leur propre Musonic Server, ou qui veulent savoir exactement comment Musonic fonctionne. Si un proche vous a installé Musonic, vous n'en avez pas besoin : l'appli s'utilise comme les autres applis de musique.

## Par où commencer

- **[Installer le serveur avec Docker](/fr/docs/install/docker/)** : d'une machine Linux vide à votre premier compte, en une dizaine de minutes.
- D'autres pages arrivent : connecter les applis, venir de Navidrome, qualité audio, vie privée, sauvegardes.
